# Context

Reusable DCA organisational context for AI systems.

Context should point to or summarize canonical DCA sources without silently replacing their authority.

Current starting point:

- `current-authority.md` — AI-facing map of current architecture, current organisational reality sources, working sources, and historical/non-current structural material.

- `identity-migration-r01.md` — observed bounded Dev/Test build and test results, unresolved repairs/review/runtime checks, and the separate intended production candidate; not a production write route.

Context may later include organisation-wide terminology, source maps, and bounded domain context. Context is not itself organisational authority.
