# Legacy Skills

Historical DCA AI skills preserved for reference and continuity.

These skills were created under the pre-reality-first DCA system model and are **not current DCA AI capabilities**. They must not be loaded or used by Claude, ChatGPT, Airtable Omni, or another runtime as active skills unless they are explicitly re-audited and replaced by a current provider-independent skill definition.

Preserved legacy skills:

- `dca-system-architect/` — historical fixed Layer / Entry Point / Anchor system-architecture skill;
- `dca-logistics-architect/` — historical logistics skill derived from that earlier model.

Current skills belong directly under `/skills/` and must follow current DCA authority, methods, workflows, and provider-independence rules.
