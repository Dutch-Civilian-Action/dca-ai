# Claude Skill Implementations

Claude-specific packaging, configuration, or adapters for current DCA skills may be placed here when needed.

Canonical skill definitions remain under `/skills/` and should stay provider-independent wherever practical.

This directory is currently prepared but intentionally contains no active Claude-specific skill implementation yet.

Do not load or reuse `/skills/legacy/` as current Claude skills. Legacy material may be consulted only as historical reference after its status is made explicit.
