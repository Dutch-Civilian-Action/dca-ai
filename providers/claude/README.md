# Claude

Claude is the current official DCA AI runtime.

This area is for Claude-specific instructions, configuration, packaging, and implementation details needed to run DCA AI capabilities in Claude.

Canonical DCA organisational meaning remains outside provider-specific configuration. Claude applies DCA specifications; it does not define organisational truth by itself.

## Required authority inputs

Any current Claude configuration for DCA should apply, at minimum:

- `../../governance/authority-rules.md`
- `../../context/current-authority.md`
- the current canonical DCA architecture referenced by those files

Claude must not fall back to the pre-reality-first fixed Layer / Entry Point / Anchor model merely because legacy instructions or historical documents remain accessible.

Provider-specific prompts may adapt formatting and execution behaviour, but they must not redefine DCA organisational authority.
